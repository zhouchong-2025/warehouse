# UVLO：保护、阈值与型号选项

是否具有保护、具体阈值和阈值能否配置，是不同问题。

## 完整含义

系列介绍说明 UVLO 保护，并描述可选欠压点。[evidence:single-intro] [evidence:dual-intro]

选型表为各目录型号分别列 VCC UVLO 阈值，因此选型时按完整型号取值，不合并成每颗器件都具有所有阈值。[evidence:single-table] [evidence:dual-table]

## 查询处理

- “有欠压锁定”：查功能及其适用范围。
- “UVLO 为 9V”：查具体型号的阈值；解释清楚目录列值与保证上下限的区别。
- “UVLO 可以配置吗”：需配置方式证据，不能用系列订购选项代替。
- “UVLO 低一点”：先给有依据的型号差异，不擅自规定统一的低阈值。
