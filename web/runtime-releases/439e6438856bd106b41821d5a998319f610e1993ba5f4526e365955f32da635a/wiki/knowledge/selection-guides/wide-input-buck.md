# 宽输入 Buck：工作范围与控制方式

以 NSR10A 三个目录型号对照验证知识契约，不给“宽输入”建立统一阈值。

## 工程师问题

“宽输入”是工程师可能提出的需求。用户给定输入范围时，检查器件工作范围是否覆盖，并结合条件；没有给出范围时先比较参数，不擅自把该词解释成某个统一阈值。

## 型号差异

选型表中这三个型号的输入列相同，输出电流和封装不同，控制方式列为 COT。不能根据共同介绍把同系列的最大输出电流赋给所有型号，也不能将 COT 改成峰值电流模式。[evidence:buck-table]

## 保留的问题

用户若提出“要 peak current mode”，需对照实际控制方式；若只问“输入宽一些”，可以展示已有范围及差异，再根据应用决定是否需要澄清。没有足够条件时不能保证完整电源方案可行。
